Política de Privacidad de Pitch-Doctor

Última actualización: 8 de octubre de 2026

Pitch-Doctor es una herramienta de diagnóstico creada por Zero Digit X (Mario Alvarez) para escanear sitios web públicos y generar reportes de auditoría enfocados en el negocio. Esta política explica qué información recopilamos, cómo la usamos y tus derechos.

Información que Recopilamos

  • La URL del sitio web que ingresas para el escaneo.
  • La dirección IP del dispositivo que realiza el escaneo (recopilada automáticamente por nuestro servidor).
  • Nombre del negocio, ciudad, nombre de marca y correo electrónico que proporcionas al llenar el formulario de escaneo: se usan para personalizar tu reporte y para seguimiento de leads.
  • Una captura de pantalla de tu sitio web tomada durante el escaneo (vistas tanto en móvil como en escritorio).
  • Detalles técnicos que descubrimos durante el escaneo: título de la página, meta tags, enlaces, certificados SSL, datos estructurados y otra información públicamente disponible.

Cómo Usamos Tu Información

  • Generar el reporte de auditoría y mostrártelo en tu navegador.
  • Guardar el reporte como un archivo HTML con URLs firmadas HMAC para que solo tú (o cualquiera con el enlace exacto) pueda acceder a él.
  • Almacenar información básica de leads (correo, nombre del negocio, ciudad, URL escaneada, puntaje) en un archivo local de leads para análisis de negocio.
  • Enviar solicitudes a servicios de terceros únicamente como parte del escaneo: Google Maps / Google Business Profile API (si se configura una clave), y cualquier otro servicio necesario para realizar la verificación de salud.
  • Mantener el servidor en funcionamiento mediante pings de health-check (monitor de Render) — esto no recopila datos personales.

Retención de Datos

  • Los reportes se almacenan como archivos HTML en el servidor hasta que se eliminen manualmente.
  • Los datos de leads (correos, nombres de negocios, ciudades) se almacenan en un archivo JSON local y solo son accesibles para el operador de la instancia de pitch-doctor.
  • Los datos de limitación de frecuencia (basados en IP, 10 escaneos por 60 segundos) se mantienen solo en memoria y se pierden cuando el servidor se reinicia.
  • Si estás ejecutando tu propia instancia de pitch-doctor, todos los datos se quedan en tu servidor — nada se envía a terceros excepto la llamada opcional a Google Places API.

Servicios de Terceros

  • Google Places / Google Business Profile API — utilizada para buscar fichas de negocios. Requiere una clave API separada. Los datos devueltos se usan solo para generar el reporte.
  • Servicios de renderizado (Playwright / navegador sin cabeza) — utilizados para capturar capturas de pantalla. Los datos de las capturas se almacenan localmente junto con el reporte.
  • Render.com — la plataforma de alojamiento de la instancia hospedada de pitch-doctor. La política de privacidad de Render se aplica a los registros de infraestructura del servidor.

Tus Derechos

  • Puedes solicitar la eliminación de tus datos de lead contactándonos en mariosalvarez.com.
  • Puedes solicitar una copia de cualquier dato que tengamos sobre ti enviando un correo a la misma dirección.
  • Los reportes contienen URLs firmadas HMAC; si crees que un enlace de reporte ha sido comprometido, contáctanos y lo revocaremos.

Privacidad de Menores

  • Pitch-Doctor es una herramienta de negocios dirigida a dueños de sitios web, agencias y mercadólogos. No recopilamos intencionalmente información personal de niños menores de 13 años.

Cambios en Esta Política

  • Podemos actualizar esta política de vez en cuando. Los cambios se publicarán en esta página con una fecha actualizada.
